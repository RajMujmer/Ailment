# Ailment Prophet 

This repository contains the codebase for "Ailment Prophet". These is Disease Prediction Streamlit App. The training notebooks &amp; the datasets are also provided in the respective folders. 

app.py is the streamlit app code.
run the command "**pip install -r requirements.txt**" to install the required dependencies for the streamlit app.

You may need to install additional libraries for running the jupyter notebooks.



For my Python project on ailment detection, I applied my skills in machine learning, data preprocessing, and model deployment
to develop a system that predicts heart disease, diabetes, and Parkinson's disease. The project leverages datasets containing
medical records and symptom-based data to train models capable of detecting these conditions. I started by collecting and 
preprocessing medical datasets, ensuring proper handling of missing values and standardizing numerical features. Feature
selection techniques were used to identify the most relevant parameters, such as blood pressure, glucose levels, heart rate,
and voice impairments for Parkinsons disease. For model training, I implemented classification algorithms including Logistic 
Regression, Decision Trees, Random Forest, and Support Vector Machines (SVM). Each model was trained and evaluated using accuracy,
precision, recall, and F1-score metrics to determine the best-performing algorithm for each disease. To make the project 
user-friendly, I developed an interactive interface using Streamlit, allowing users to input medical parameters and receive disease
predictions instantly. This step required integrating Python libraries like Pandas, NumPy, Scikit-learn, and Matplotlib. 
The final model was deployed on Streamlit Cloud, making it accessible for real-world testing. Through this project, I enhanced my 
skills in AI-based healthcare solutions, machine learning, cloud deployment, and user-friendly application development. 
It reinforced my understanding of practical implementations in medical diagnostics, making predictive healthcare accessible to users.
